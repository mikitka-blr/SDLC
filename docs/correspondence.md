Вопросы справедливые, объясню, из чего складываются сроки.

**Статистика (6 дней).** Число выученных карточек — это лишь верхушка. Нужно вести журнал каждой оценки, чтобы считать среднюю оценку и находить «западающие» карточки (две и более оценки «плохо»). Затем — запросы к базе с группировкой по предметам, таблица с прогресс-барами, панель «западающих» тем с кнопкой «Тренировать» и проверка скорости на 5000 карточек. Отдельно в эти 6 дней входил фильтр по периоду (7 дней, 30 дней, всё время): ему нужны отдельные запросы, граничные случаи по датам и тесты.

**Импорт CSV (5 дней).** Загрузка файла — это не одна кнопка. Нужны: вход по паролю с безопасным хранением (в виде хэша, а не открытого текста), разбор файла, обработка кодировок (Excel сохраняет CSV не в UTF-8, и русский текст превращается в «кракозябры»), проверка дублей, откат всех изменений, если ошибка на 300-й строке, и понятное сообщение об ошибке. Плюс тесты, потому что на этой функции легко потерять данные.

Тесты я не предлагаю убирать: экономия на них оборачивается ошибками у пользователя и переделками, которые дороже.

**Что можно сократить без ущерба для главной цели (подготовка по карточкам):**

1. Фильтр статистики по периоду сделать необязательным (Could). Статистика останется: прогресс, средняя оценка и «западающие» карточки. Экономия — 2 дня.
2. Импорт CSV упростить: только файл в UTF-8 по готовому шаблону, без предпросмотра; при ошибке — откат и сообщение с номером строки. Экономия — 2 дня.
3. Функцию F10 (горячие клавиши, теги, подсказки) перенести на релиз 2.0. Экономия — 3 дня.

Итого вместо 44 дней получится 37, а в срок в 40 дней останется резерв в 3 дня. Как вам такой вариант?
