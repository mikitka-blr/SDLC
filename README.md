# Инвертор слов (вариант №8)

**Студент:** Григорчик Никита, группа 450504

**Дисциплина:** Жизненный цикл разработки программного обеспечения

**Описание проекта:**
Приложение для инвертирования слов в предложении. Пользователь вводит 
предложение, программа формирует предложение с инвертированными словами.

**Технологии:**
- Язык: Java
- Среда разработки: IntelliJ IDEA
- GUI: Swing
- Архитектура: MVC с активной моделью
